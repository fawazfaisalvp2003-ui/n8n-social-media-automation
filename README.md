# n8n Social Media Automation

An automated social media content generation workflow built using n8n, Google Sheets, Google Gemini AI, and LinkedIn.

## Workflow

Google Sheets Trigger
        ↓
Summarize Articles
        ↓
Google Gemini
        ↓
Basic LLM Chain
        ↓
LinkedIn – Create a Post

## Technologies Used

- n8n
- Google Sheets
- Google Gemini AI
- LinkedIn
- Large Language Models (LLM)

## Features

- Monitors data from Google Sheets
- Summarizes articles using Gemini AI
- Generates social media content
- Automatically creates LinkedIn posts

## How to Use

1. Download the workflow JSON file.
2. Open n8n.
3. Import the JSON workflow.
4. Configure your Google Sheets credentials.
5. Configure Google Gemini credentials.
6. Configure LinkedIn credentials.
7. Activate the workflow.

## Workflow Preview

The workflow automates the process of converting article information into social media content and publishing it to LinkedIn.
